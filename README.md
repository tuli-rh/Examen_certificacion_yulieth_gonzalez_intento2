# Querido Diario

**Querido Diario** es una app personal pensada para que cada usuario pueda escribir, guardar y organizar experiencis.

## como utilizar la pagina 
* **Crear tu cuenta:** debes completar todos los campos y ser mayor de edad para poder ingresar.
* **Tus notas:** cuando inicies sesion podras ver solo tus notas.
* **Buscar notas:** Encuentra momentos especificos usando la barra de búsqueda por palabras clave.
* Nadie más puede ver, editar ni borrar lo que escribes.

## tecnologias 
* Python con Flask
* MySQL
* HTML, CSS y Jinja2
